# MAQSOUD / مقصود — Malaz source record

This directory contains the source-of-truth dataset and the real public assets selected for the Menu demo. The menu records are based on the current HungerStation Arabic and English MAQSOUD Malaz listings, with the Malaz address cross-checked against The Chefz and Waze. Items shown with a zero price in the source listing were excluded rather than presented as free or assigned an invented price.

The logo and hero assets are copied from the current MAQSOUD Malaz public listing imagery returned by the image search for HungerStation. No generated food photography is used. The food image is retained as a source reference only and is not assigned to a product because a product-specific mapping was not verified.

No phone number, operating hours, WhatsApp number, Instagram account, or product-specific image is inserted because the available public sources did not establish a sufficiently reliable current value for those fields. WhatsApp remains hidden in the customer menu until a restaurant-provided WhatsApp-capable destination is verified.
